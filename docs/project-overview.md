# 项目说明

## 1. 项目定位

「工具箱」是一个面向安卓真机的轻量 Expo 应用，用于：

1. 演示常用系统能力（震动、电量、传感器等）；
2. 通过系统 **AccessibilityService** 完成「快手极速版」日常签到辅助。

项目偏个人 / Demo 用途，不面向应用商店分发，不承诺兼容所有机型与快手版本。

## 2. 目标用户与场景

| 场景 | 说明 |
| --- | --- |
| 日常签到 | 用户手动点「自动签到」，应用拉起快手并尽量完成去赚钱 → 签到 |
| 能力验证 | 在「系统能力实验室」验证 Expo 模块在真机 / Web 上的表现 |
| 开发联调 | 用 EAS APK 验证本地 Expo Module 与无障碍行为 |

## 3. 范围

### 做

- 工具箱首页聚合入口
- 快手极速版（包名 `com.kuaishou.nebula`）签到自动化
- 无障碍开关检测、设置跳转、电池优化引导
- 签到过程步骤条 + 实时日志 + Toast
- 设备信息 / 震动 / 亮度 / 剪贴板 / 分享等 Demo

### 不做

- 后台定时静默签到（无常驻调度、无账号体系）
- 绕过系统安全策略的「永久无障碍授权」
- iOS 无障碍自动化（`auto-assist` 仅 Android）
- 对快手内部私有协议 / Hook 逆向

## 4. 运行环境

| 环境 | 能做什么 |
| --- | --- |
| Web (`pnpm web`) | 浏览 UI、部分 Demo；无法使用无障碍 |
| Expo Go | 同上；原生模块不可用 |
| EAS APK（`preview`） | 完整能力，含无障碍自动签到 |
| 本地 `expo run:android` | 开发构建，同样可带原生模块 |

## 5. 依赖与配置要点

- 包管理：`pnpm`（见根目录 `packageManager`）
- 本地模块：`"auto-assist": "file:./modules/auto-assist"`
- 应用配置：`app.json`（名称、包名、图标、EAS projectId）
- 云构建：`eas.json` → `preview` 产出 APK
- 原生目录 `android/` / `ios/`：CNG 生成，不入手改；原生能力写在 `modules/auto-assist` 与 `app.json`

## 6. 版本与发布

- 展示版本以 `app.json` → `expo.version` 为准
- 日常安装包：`pnpm build:apk`（`eas-cli@26.0.0` + `preview` profile）
- 覆盖安装后**必须重新开启**无障碍服务

## 7. 风险与合规提示

无障碍可读取界面并模拟手势，权限敏感。请仅在自有设备上、用于辅助本人操作；遵守目标应用服务条款与当地法规。厂商 ROM 的杀后台策略会导致服务不稳定，属系统行为，非本应用可完全控制。
